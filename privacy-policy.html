Privacy Policy — Simo Publish Hub

Effective date: October 15, 2026

Simo Publish Hub ("the tool") uploads original videos to our own YouTube channels using the YouTube Data API v3. This policy explains what data the tool accesses, how it is used, and what it never does.

What the tool does

The tool publishes videos we created to our own YouTube channels:

  • One Clear Choice Stoicism (@oneclearchoice)
  • Stoic Stop (@stoicstopquotes)

Each upload is an original video produced by us. The tool does not upload anyone else's content.

YouTube API — Data Use

The tool uses the YouTube Data API v3 with a single OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload (upload-only)

API calls made by the tool:

  • videos.insert — resumable upload, parts snippet and status. Sends only the video file and the metadata we provide: title, description, tags, category, and privacy status.
  • thumbnails.set — sets the custom thumbnail image we provide for the uploaded video.

That is all. The tool makes no other YouTube API calls.

What data we do NOT access

  • No viewer data (no watch history, no viewing activity).
  • No comments — the tool never reads, posts, or manages comments.
  • No analytics, reports, or channel statistics.
  • No subscriber lists or subscriber data.
  • No data about other channels or other users.

How authorization works

Uploads are authorized with OAuth tokens for our own Google account. The tokens are stored on our own server and authorize only uploads to our own channels. Tokens are never shared, sold, or given to any third party. If you are the account owner and want access revoked, remove the app's access in your Google account permissions — uploads stop immediately.

Data sharing and retention

We do not sell, rent, or share any data with third parties. Uploaded videos and their metadata live on YouTube under our own channels, subject to YouTube's own policies. We keep no copy of viewer or user data because we never collect any.

Changes to this policy

If the tool's data use changes, this page will be updated and the effective date above will change.
